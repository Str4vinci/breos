# Design notes

This directory keeps architecture notes, design proposals and architecture
decision records in the repository without publishing them as BREOS user
documentation.

These notes give maintainers and contributors the reasons behind the code.
Each note states whether it describes the current design or a proposal.
Current capabilities belong in `docs/`; future release intent belongs in
`ROADMAP.md`.

- [`architecture/`](architecture/README.md) — architecture notes, policies and proposals
- [`adr/`](adr/index.md) — architecture decision records
